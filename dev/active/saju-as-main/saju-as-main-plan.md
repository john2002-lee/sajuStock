# 사주를 메인으로 — 승인된 계획

## 배경

주식 서비스는 앞으로 **개발만** 하고, 사주 풀이가 제품의 메인이 된다.
제품 이름은 **FEEL** 로 통일한다(기존 "천명" · "종목 원장" 대체).

## 승인된 결정

| 항목 | 결정 |
|---|---|
| 루트(`/`) | **루트 자체를 사주 화면으로.** 리다이렉트가 아니라 `app/(saju)/page.tsx` |
| `/saju` | `proxy.ts` 에서 `/` 로 307. **정확히 `/saju` 만** |
| 주식 차단 수준 | **링크만 감춘다.** 주소를 직접 치면 열린다 |
| 주식 입구 | 관리자 화면(`AdminShell`) 탭 줄 우측에 "주식 서비스 →" |
| `ServiceBar` | **삭제** (한 서비스만 남아 한 칸짜리 탭바가 됨) |
| 제품 이름 | **FEEL** 로 통일 |

## 왜 페이지 `redirect()` 가 아니라 `proxy.ts` 인가

루트 `loading.tsx` 가 만든 Suspense 경계 때문에 셸이 먼저 흘러나가, 페이지에서
`redirect()` 를 부르면 307 이 아니라 `<meta http-equiv="refresh">` 로 내려간다.
골격이 1초 보였다 넘어간다 — 랜딩에서 그건 첫인상을 깬다.
`src/proxy.ts` 에 실측으로 기록된 함정이고, 대시보드가 이미 같은 이유로 proxy 에서 끊는다.

## 범위 밖

- 주식 서비스 자체의 기능 변경
- 주식 접근 차단(로그인 게이트 · 환경변수 스위치)
- 친구 공유 버튼 — **이 작업 다음에** 별도로 올린다(루트가 사주가 되면 공유 주소가
  `aiot21.com` 으로 딱 떨어져 설계가 단순해진다)
